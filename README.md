# Sombras del Arte

Proyecto realizado para la asignatura **Lenguajes de Marcas (DAM M04)**.

## Descripción
Sombras del Arte es una página web estática desarrollada desde cero utilizando **HTML5 y CSS3**.  
El objetivo de la práctica es aplicar los conocimientos básicos de estructura HTML, estilos CSS, uso de multimedia y publicación del proyecto mediante **GitHub Pages**.

La web está orientada a contenidos culturales y artísticos, centrados principalmente en el cine y la literatura.

## Objetivo de la práctica
- Crear una página web desde cero sin usar CMS
- Utilizar HTML5 y CSS3 correctamente
- Trabajar el proyecto con **Visual Studio Code**
- Publicar la web en **GitHub**
- Practicar el uso de **Git y commits**
- Incluir contenido multimedia
- Validar el código HTML y CSS

## Estructura del sitio
La web está compuesta por las siguientes páginas:
- **Cine**
- **Literatura**
- **Contacto**

## Tecnologías utilizadas
- HTML5
- CSS3

## Contenido multimedia
La web incluye:
- Imágenes
- Audio
- Vídeo
